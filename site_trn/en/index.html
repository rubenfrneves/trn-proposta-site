Frequently asked questions

What is needed to request a quote?

Departure and destination, date and time of departure, number of passengers and expected luggage.

Is it possible to make several stops?

State the stops in the request, in order and with the planned time at each. The quote considers the full route.

How does the return work?

State whether there is a return, the date, time and pick-up point. If it is on another day, mention it in the notes.

What luggage can be carried?

State the quantity and type of luggage. The team confirms whether the suggested vehicle is suitable.
